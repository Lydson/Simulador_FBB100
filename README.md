# 🎯 Simulador FBB100

Um simulador web interativo e responsivo desenvolvido para auxiliar nos estudos da certificação **Febraban FBB100 (Correspondente Completo)** e na compreensão da **LGPD (Lei Geral de Proteção de Dados)** no setor financeiro.

## 🚀 Funcionalidades

- **3 Modos de Simulado:**
  - **Rápido:** 10 questões para uma revisão ágil.
  - **Médio:** 30 questões para um treino intermediário.
  - **Completo:** 60 questões simulando a extensão real da prova oficial.

- **Banco de Questões Inéditas:** Questões elaboradas com base nos conceitos do SFN, CDC, Matemática Financeira, Consignado, Veículos e LGPD, evitando plágio e focando no aprendizado real.

- **Mecânica de Estudo:**
  - **Shuffle:** Questões e alternativas embaralhadas a cada nova tentativa.
  - **Feedback Instantâneo:** Explicações detalhadas (justificativas) após cada resposta baseadas na legislação vigente.
  - **Navegação Flexível:** Botões para avançar, voltar ou sair do simulado a qualquer momento.

- **Análise de Desempenho:**
  - Cronômetro em tempo real para controle de tempo de prova.
  - Cálculo de porcentagem de acertos (Corte de aprovação: 70%).
  - **Diagnóstico de Erros:** Lista automática dos temas que precisam de mais atenção com base nos erros cometidos.

- **Design Moderno:** Interface limpa, intuitiva e totalmente responsiva (Mobile & Desktop).

## 🛠️ Tecnologias Utilizadas

## 📦 Como rodar o projeto localmente

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/Lydson/Simulador_FBB100.git](https://github.com/Lydson/Simulador_FBB100.git)

```

2. **Entre na pasta do projeto:**
```bash
cd Simulador_FBB100

```


3. **Instale as dependências:**
```bash
npm install

```


4. **Inicie o servidor de desenvolvimento:**
```bash
npm run dev

```


Acesse `http://localhost:5173` no seu navegador.

## 🌐 Deploy

O projeto está configurado para ser facilmente publicado no **GitHub Pages** ou **Vercel**.

Para publicar no GitHub Pages:

```bash
npm run deploy

```
